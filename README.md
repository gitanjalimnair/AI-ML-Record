# 🤖 AI & Machine Learning Projects

This repository contains a collection of Artificial Intelligence, Machine Learning, Deep Learning, Computer Vision, Reinforcement Learning, and Generative AI projects developed using Python and modern AI frameworks.

---

## 📂 Projects

### 🧠 Machine Learning

- **Adult Census Income Classification**
  - Predict whether an individual's annual income exceeds \$50K using demographic and employment-related features.

- **Student Placement Predictor**
  - End-to-end machine learning web application that predicts student placement using academic and skill-based features.

- **Car Price Predictor**
  - End-to-end machine learning web application that estimates used car prices based on vehicle specifications.

- **Movie Recommendation System**
  - Content-based recommendation engine using NLP, CountVectorizer, and Cosine Similarity.

---

### 👁️ Computer Vision & Deep Learning

- **CIFAR-10 Image Classification using CNN**
  - Convolutional Neural Network for multi-class image classification on the CIFAR-10 dataset.

- **Face Recognition using CNN (LFW Dataset)**
  - Face recognition model trained using the Labeled Faces in the Wild (LFW) dataset.

- **Cancer Detection using MRI Images**
  - Deep learning model for detecting tumors from MRI scans.

---

### 🎮 Reinforcement Learning

- **CartPole RL Agent Training**
  - Deep Q-Network (DQN) agent trained to solve the CartPole-v1 environment.

- **Lunar Lander RL Agent Training**
  - Reinforcement Learning agent trained to successfully land a spacecraft using OpenAI Gym.

---

### 🤖 Generative AI

- **RAG Chatbot (Capstone Project)**
  - Retrieval-Augmented Generation chatbot for querying PDF documents using Google Gemini, LangChain, and FAISS.
